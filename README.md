# FinTrack

Dashboard financeiro desenvolvido para praticar conceitos de front-end no curso de Análise e Desenvolvimento de Sistemas.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Chart.js

## Funcionalidades

- Dashboard com saldo, receitas e despesas
- Gráfico de gastos por categoria
- Cadastro de novas transações
- Atualização automática dos totais
- Layout responsivo
- Interface em modo escuro

## Como executar

1. Baixe ou extraia a pasta do projeto.
2. Abra a pasta no VS Code.
3. Abra o arquivo `index.html` no navegador.

Para uma experiência melhor, use a extensão **Live Server** no VS Code.
